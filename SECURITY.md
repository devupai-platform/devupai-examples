# Security Policy

## Reporting a Security Issue

Do not report security issues or vulnerabilities publicly (e.g., via GitHub Issues).

If you discover a security issue, please email us directly at **support@devupai.com**. We take all security reports seriously and will respond promptly.

## Security Best Practices for Examples

These examples are intended as educational starters. When taking these examples to production, please note:
- **Never commit API keys**. Ensure they are kept out of source control.
- **Never expose keys through `NEXT_PUBLIC_*`** variables or bundle them into client-side code.
- Examples may lack production-grade hardening. Always review and harden code for your specific deployment environment.
